# Vaibhav Pandey — Portfolio

A responsive, single-file portfolio site highlighting my backend engineering experience, selected projects, technical skills and contact links.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder to publish the repository root, or move `PORTFOLIO_SITE/index.html` to the root first.

This site currently lives in `PORTFOLIO_SITE/` to avoid replacing this repository's existing Java DSA content. For a clean standalone site, copy `PORTFOLIO_SITE/index.html` to the root of a dedicated repository named `Vaibhavpandey999.github.io` (if available) or a `portfolio` repository, then enable Pages.

## Notes

- Static HTML/CSS/JS; no build step is required.
- Content is based on the resume and public repository descriptions available when prepared.
- Public contact details are displayed as included in the resume.
